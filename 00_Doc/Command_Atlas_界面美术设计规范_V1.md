## 1. 设计概念：工程图集（Engineering Atlas）

「Atlas」是地图集。设计语言围绕三个关键词展开：

| 关键词 | 视觉表达 |
|---|---|
| **图集 / 定位** | 顶部"产品上下文栏"像地图标题（你正在查看哪张图）；细网格底纹、坐标感；定位标记 ⌖ 作为产品档案图标 |
| **协议 / 字节** | 帧 = 一排"字节格"，像地图上的等高线区块；固定段、参数段、计算段用不同色块区分，一眼看出"哪几个字节是我填的" |
| **可信 / 出版** | 数据版本、来源提交 SHA 像书籍版权页的"版次印次"，以徽章（badge）形式常驻页脚；已验证 = 有印章 |

气质：**安静的工程工具**——白底、克制的蓝、充足留白；不用渐变炫光、不用圆角卡片堆叠、不用阴影层级轰炸。让人联想到"高精度的技术手册"而不是"消费级 App"。

## 2. 色彩系统（V1 仅亮色主题）

### 2.1 中性色（纸面 + 墨色）

| Token | 色值 | 用途 |
|---|---|---|
| `bg_app` | `#F4F6F9` | 窗口底色（纸面灰） |
| `bg_card` | `#FFFFFF` | 卡片、面板、输入框 |
| `bg_hover` | `#EEF1F6` | 列表悬停、浅底 |
| `border` | `#DDE3EC` | 分割线、控件边框 |
| `border_strong` | `#B9C3D4` | 聚焦前边框加深处 |
| `text_primary` | `#1C2434` | 标题、正文 |
| `text_secondary` | `#5B6676` | 说明、次要信息 |
| `text_disabled` | `#9AA4B5` | 禁用、占位 |

### 2.2 主色（Atlas 蓝）

| Token | 色值 | 用途 |
|---|---|---|
| `primary` | `#2456E6` | 主按钮、选中态、链接 |
| `primary_hover` | `#1B45C4` | 悬停/按下 |
| `primary_bg` | `#EAF0FE` | 选中行背景、主色浅底 |
| `primary_border` | `#B9CCF9` | 选中框描边 |

### 2.3 语义色

**风险分级（指令）**——全软件唯一的风险色表，查询页徽章、详情页警告、录入页都复用：

| 级别 | 名称 | 色值 | 用法 |
|---|---|---|---|
| L0 | 只读 | `#16A34A`（绿） | 徽章 + 浅绿底 `#E7F6EC` |
| L1 | 可恢复设置 | `#2456E6`（主蓝） | 徽章 + 浅蓝底 `#EAF0FE` |
| L2 | 高风险设置 | `#C77400`（琥珀） | 徽章 + 浅琥珀底 `#FBF0DC`，必须配警告文案与二次确认 |
| L3 | 破坏性/工厂 | `#DC2626`（红） | 仅研发录入工具可见；公开库不发布 |

**同步状态（对齐策划 §8.2 四态）**：

| 状态 | 色值 | 图标 |
|---|---|---|
| 已同步（绿） | `#16A34A` | ✓ |
| 离线使用本地版本（黄） | `#B8860B` | ◐ |
| 发现新版/正在同步（蓝） | `#2456E6` | ↻ |
| 同步失败，本地可用版本已保留（红） | `#DC2626` | ⚠ |

**校验/测试**：通过 `#16A34A`、失败 `#DC2626`、警告 `#B8860B`；成功/失败不用色块铺底，只用 16px 圆点 + 文字。

### 2.4 帧字节配色（产品最具辨识度的部分）

帧预览使用**深色代码底** `#161B26`，字节以等宽 chip 排列：

| 段类型 | chip 底色 | 文字色 | 含义 |
|---|---|---|---|
| 固定段 | `#2A3244` | `#A9B4C9` | 协议固有字节 |
| 参数段 | `#2456E6`（实心） | `#FFFFFF` | 用户填的字段——**必须最醒目** |
| 计算段 | `#3B2E7A` | `#C4B5FD` | BCC/长度等系统计算 |
| 高亮选中字节 | `#0EA5A5` | `#FFFFFF` | 点击字节时与右侧字段拆解联动 |

ASCII 帧同样深色底、字节等宽排列，不换行折行，超长横向滚动。

## 3. 字体与排版

| 用途 | 字体 | 字号（Qt pt） | 字重 |
|---|---|---|---|
| 界面正文 / 控件 | 微软雅黑（Microsoft YaHei UI） | 9 pt | Regular |
| 区块标题 | 微软雅黑 | 11 pt | SemiBold |
| 页标题 / 指令中文名 | 微软雅黑 | 14 pt | SemiBold |
| 搜索框提示 | 微软雅黑 | 12 pt | Regular |
| **HEX / ASCII 帧、字节、SHA、版本号** | Consolas（首选）/ Cascadia Mono | 10–13 pt | Regular / Bold（帧用 12pt Bold） |
| 风险/状态徽章 | 微软雅黑 | 8.5 pt | Medium |

规则：

- 任何**机器数据**（帧字节、SHA-256、版本号、IP）一律等宽字体，与用户输入的"自然语言"在视觉上严格区分。
- 帧预览区最小字号 12pt，售后现场小屏/老花也要看得清。
- 不使用斜体；中文不用宋体系。

## 4. 间距、圆角、控件基准

- **网格**：4 px 基准间距。页面外边距 16 px；卡片内边距 12–16 px；控件间距 8 px。
- **圆角**：卡片 8 px，输入框/按钮 6 px，字节 chip 4 px，徽章 10 px（胶囊）。
- **控件高度**：常规 32 px，表格行内紧凑控件 26 px，搜索主框 40 px。
- **阴影**：仅弹出层（下拉、悬浮卡）使用 8% 透明度投影；卡片一律无阴影，用 1 px 边框 `#DDE3EC` 分界。
- **窗口基准**：最小 1100 × 700，默认 1280 × 800；所有三页在 125% 缩放下不破版。

## 5. 组件规范

### 5.1 按钮

| 类型 | 样式 |
|---|---|
| 主按钮（如"复制指令"） | 实心主蓝、白字、高 40 px、圆角 6 px；悬停 `#1B45C4`；左侧带 16px 线性图标 |
| 次按钮 | 白底、1 px 主蓝描边、主蓝文字 |
| 文字按钮 | 无主色底，用于"导出/设置"等低频操作 |
| 危险操作（录入工具删除） | 红描边红字，需二次确认 |

复制成功后主按钮短暂变为绿色 ✓"已复制"（1.2 秒回弹），给售后明确的完成反馈。

### 5.2 徽章（badge）

风险徽章 = 胶囊形：浅底色 + 深色文字 + 左侧 6 px 圆点，高 20 px。例：`● 只读`、`● 高风险`。

### 5.3 同步状态徽章（常驻顶部栏右侧）

四色圆点 + 简短文案 + 悬浮提示详情（数据版本、上次成功时间、来源 SHA）。**悬浮展开是详细卡片，不跳转页面**。

### 5.4 搜索框

- 查询页顶部通栏大搜索框：40 px 高、左侧 ⌕ 图标、圆角 8 px、白底。
- 输入时下方即时出"建议"下拉（最近使用 + 收藏优先，其次别名命中）。
- 无结果时显示空态插画 + 明确文案"暂无已发布指令"（**绝不出现在结果中编造字节**）。

### 5.5 参数表单

- 每个参数一行：中文标签（如"通道"）＋ 输入框 ＋ 单位/值域提示（灰色小字，如"1~40"）。
- 越界输入：输入框红描边 + 行内即时错误提示，**复制按钮同时禁用**。
- 语义搜索预填的值以普通文本填入，不特殊标记（但保留策划要求：用户必须确认后才生成）。

### 5.6 字节地图（帧预览，双端共用）

深色底上一排等宽 chip；chip 下方一条"段带"标注各段归属（帧头/命令/参数名/BCC）。点击参数 chip → 右侧字段拆解区对应行高亮。详情页与研发录入工具完全同一组件、同一配色。

### 5.7 图标

- 线性 SVG、1.5 px 描边、圆头端点，三档 16 / 20 / 24 px。
- 图标清单（首版）：搜索 ⌕、产品/档案 ⌖、收藏 ☆、历史 ◷、同步 ↻、复制 ⧉、导出 ⇩、警告 ⚠、字节段 ▦、校验 ✓、设置 ⚙。
- 应用图标：罗盘 ⌖ 与字节网格结合的扁平图形，主蓝 `#2456E6` 单色系，EXE ICO 含 16–256 px 九档（做法可复用串口工具 `resources/ICON.md` 流程）。


结构说明：

1. **上下文栏**：左 = 品牌 + 产品/型号/固件下拉（未选时搜索框禁用，落实"不静默生成"原则）；右 = 同步徽章 + 设置入口。
2. **左列（结果列表，宽 ~32%）**：每条显示中文名、风险徽章、协议·命令字、**匹配原因**（"别名'调光'命中"），可解释排序的可视化。
3. **中列（详情 + 组帧，宽 ~44%）**：说明 → 参数表单 → 字节地图 → 人类可读解释 → 复制/导出主操作。
4. **右列（宽 ~24%）**：最近使用、收藏、数据档案（版本/SHA/同步时间）。

### 6.3 同步设置页

- **状态大卡**：四态之一占据卡片顶部（大圆点 + 状态文案 + 数据版本 + 来源提交 SHA + 上次成功时间），按钮"立即检查更新"。
- **配置区**：仓库地址、项目 ID、分支（固定 main，只读展示）、证书说明；改动需保存。
- **快照与回退**：本地快照列表（版本、SHA、激活时间、回退按钮），当前激活行高亮。
- **同步日志**：等宽字体小字滚动区，仅研发排查用，默认折叠。

## 7. 动效与反馈

- 一切动效 ≤ 200 ms，线性或 ease-out；无加载动画超过 2 s 的场景（同步走后台，界面只变徽章）。
- 复制成功：主按钮 1.2 s 绿态回弹；帧内容生成变化时字节地图以 120 ms 淡入重排。
- 禁用态一律 `text_disabled` 灰 + 不可点击光标，不允许"能点但点了报错"。

## 8. 与既有工具的关系

- 与串口测试工具、网络诊断工具组成"同族三件套"：共享 4 px 网格、徽章、等宽帧显示、状态条版式；主色允许各自一个区分色（串口工具=青，诊断工具=橙，本工具=Atlas 蓝），并排运行时一眼可辨。
- 应用图标、QRC 嵌入、EXE ICO 九档封装流程复用串口工具 `resources/ICON.md` 的既定做法。
