# Command Atlas 设计资料

最终风格已确定为 **工程图集 · 字段解剖（V2）**：以 `index.html` 的双栏与分组帧图为布局基础，融合 `mockup.html` 的浅色纸面、Atlas 蓝与控件规范。

- `approved.html`：独立文件的融合定稿预览，可直接用浏览器打开；切换协议和参数可查看显示效果。
- `index.html`：协议解剖图鉴候选，样式 `styles.css` 和脚本 `app.js` 随预览存放。
- `mockup.html`：V1 工程图集候选，保留原设计。
- `../../../00_Doc/Command_Atlas_美术定稿_V2.md`：正式色彩、字体、布局、字段图与实现约束；与候选/V1冲突时以 V2 为准。

候选中的数据、按钮和扩展功能是示意，不能自动转成软件需求。实际 Qt 应用美术接入按分阶段计划推进。
