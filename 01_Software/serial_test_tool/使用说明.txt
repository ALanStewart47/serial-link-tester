串口测试工具 V0.2.6（正式版）
作者：AlanStewart

解压后双击 serial_test_tool.exe 即可，无需安装 Qt。请整包一起拷贝，不要只拷 exe。
本绿色包只含程序、运行依赖及使用说明，不含源码。
底栏左侧版本号V0.2.6、正中链路状态、右侧AlanStewart；使用双向链路图标。

一、连接
  顶栏选「串口」或「网口」（二者不能同时开）。
  串口：选 COM、波特率后打开。
  网口：选本机网卡 -> 扫描 CH9121（也可手填 IP） -> TCP 端口默认 6600 -> 连接设备。
  配置CH9121：扫描选中设备 -> 断开透传连接 -> 配置设备 -> 修改参数 -> 写入并验证。
  可配置设备名、DHCP、IP、子网掩码、网关，以及端口1波特率/数据位/停止位/校验；端口2与其他参数保留。
  设备名支持1～20个可打印ASCII字符。DHCP开启时禁用静态地址编辑。
  写入结果须读回一致才显示“已验证”；“未确认”不代表没有写入，请重新扫描读取。
  配置前关闭官方配置工具，避免占用UDP 60000端口。配置后不会自动重连TCP。
  CH9121实机扫描/读取已通过；写入、断电保持与更多串口参数组合仍待验收。

二、页签
  收发监视：监视 + 手动发送（测试运行中只能看监视）；发送内容独占一行，按回车或点击发送。
  监视保留最近 1,000 条，超过 512 字节的长数据在监视里显示开头和总字节数。
  指令库：增删改查；可导入/导出 JSON 或 CSV（CSV 建议用 CSV UTF-8）。
  自动测试：左侧挑指令并管理发送顺序，右侧“测试设置”选择模式、间隔、次数/时长及合格线。
  点击开始后自动显示右侧“实时统计”；开始/停止与进度始终位于页面底部，可拖动分隔条调整清单宽度。
  结果与日志：并排指标、趋势、合格判定、异常明细、导出报告；小窗口可滚动查看完整内容。
  设置：日志目录、全量日志开关。

三、测试提示
  次数可选总发送条数或遍历轮数；总发送 = 计划步数 × 遍历轮数。
  指令库或自动测试点击「多通道计划」，选择新CA/旧ASCII/旧扩展协议、通道范围、功能和值。
  默认逐通道设置后读回；支持多批追加、成对移动/移除、保存/打开JSON和重启恢复。
  生成步骤等待完整响应窗口再精确比较，每步约耗时“超时＋间隔”；原始指令沿用原匹配行为。
  网口响应从实际 TCP 写入到收到首批字节，由 I/O 线程计时。最小、平均和最大都只统计匹配成功的轮次。
  响应保留微秒精度，小于1ms显示μs，达到1ms显示ms；结果页独立显示三栏响应指标。
  全量CSV的“响应ms”列保留三位小数（如0.850表示850μs），统计报告使用自适应单位。
  本机 TCP 或串口驱动确认交付整帧后，「已发送」加 1。慢链路会降低发送速度。
  丢包率、总成功率只按已结算轮次数计算，尚无结算时显示N/A。
  暂停时，已发出的检测轮照原窗口结算；完全暂停后冻结用时，继续时从下一条跑。
  旧计划的 ASCII 沿用原字节；选「ASCII（转义）」时支持 \r、\n、\t、\\、\xNN。
  点击停止立即停止后续发送，显示“正在停止”；当前轮在原有截止时间内等回复或超时，不重新计时。
  等待期间测试参数、手动发送和连接操作保持锁定；完整帧步骤仍等待完整窗口后结算。
  断链或退出保留“中断/未完成”及已收字节，不提前算成设备超时；停止的测试显示“未完成”。
  合格线看总成功率与丢包率，各步骤须过线；未完成或覆盖不全不能判定全部合格。
  升级沿用原用户指令库、收藏和连接设置；旧轮询自动转换成快照，并保留ID备份。
  试用版在旧程序中保存计划JSON后，在正式版点击「打开计划」即可导入。
  更多通道限制与判定说明见包内「多通道功能说明.md」。
  全量日志默认关；勾选后每轮都写文件，体积较大。写盘失败或队列满时，测试继续并提示日志缺失。
  看到「已写入」表示写盘已确认；测试结束后仍可能短暂显示日志收尾中。
  日志默认在 %AppData%\串口测试工具\logs。

四、运行环境
  绿色版已带 MinGW 运行库和 Qt 平台插件，一般不用另装 Visual C++。
  杀毒软件可能拦截串口/UDP 扫描，打不开时请加白名单。
