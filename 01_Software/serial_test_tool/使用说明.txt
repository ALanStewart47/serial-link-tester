串口测试工具 v0.1（第一版）
作者：alanstrwart

解压后双击 serial_test_tool.exe 即可，无需安装 Qt。请整包一起拷贝，不要只拷 exe。

一、连接
  顶栏选「串口」或「网口」（二者不能同时开）。
  串口：选 COM、波特率后打开。
  网口：选本机网卡 -> 扫描 CH9121（也可手填 IP） -> TCP 端口默认 6600 -> 连接设备。
  配置CH9121：扫描选中设备 -> 断开透传连接 -> 配置设备 -> 修改参数 -> 写入并验证。
  可配置设备名、DHCP、IP、子网掩码、网关，以及端口1波特率/数据位/停止位/校验；端口2与其他参数保留。
  设备名支持1～20个可打印ASCII字符。DHCP开启时禁用静态地址编辑。
  写入结果须读回一致才显示“已验证”；“未确认”不代表没有写入，请重新扫描读取。
  配置前关闭官方配置工具，避免占用UDP 60000端口。配置后不会自动重连TCP。
  本功能已通过软件模拟测试，真实设备互读、断电保持及实际串口通信待验收。

二、页签
  收发监视：监视 + 手动发送（测试运行中只能看监视）；发送内容独占一行，按回车或点击发送。
  指令库：增删改查；可导入/导出 JSON 或 CSV（CSV 建议用 CSV UTF-8）。
  自动测试：左侧挑指令并管理发送顺序，右侧“测试设置”选择模式、间隔、次数/时长及合格线。
  点击开始后自动显示右侧“实时统计”；开始/停止与进度始终位于页面底部，可拖动分隔条调整清单宽度。
  结果与日志：并排指标、趋势、合格判定、异常明细、导出报告；小窗口可滚动查看完整内容。
  设置：日志目录、全量日志开关。

三、测试提示
  次数 = 清单总发送条数。合格线看总成功率与丢包率，且每条已发送指令都要过线。
  全量日志默认关；勾选后每轮都写文件，体积较大。
  日志默认在 %AppData%\串口测试工具\logs。

四、运行环境
  绿色版已带 MinGW 运行库和 Qt 平台插件，一般不用另装 Visual C++。
  杀毒软件可能拦截串口/UDP 扫描，打不开时请加白名单。
