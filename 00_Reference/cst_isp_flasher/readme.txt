Bootloader 升级工具（isp_flasher）v1.2
解压后双击 isp_flasher.exe 即可，无需安装 Qt。

先在窗口顶部选串口或网口连上控制器，再选升级页。
页签：MCU 升级 / 安路 FPGA 升级 / 高云 FPGA 升级
通道：串口直连，或 CH9121 网络透传（扫描后 TCP 连接，默认端口 6600）。
固件：可点「选择固件」，或把文件拖到窗口（按当前 MCU / 安路 / 高云页校验）。

MCU 网口等待上电烧录：
- 先在设备通电时扫描并选中设备，选择 MCU 固件。
- 点击「等待上电烧录」，再给控制器断电重上电；无需先连接 TCP 或修改目标版本。
- 软件自动连接、握手并烧录一次，等待期间可点击「取消」。
- 需要 MCU Boot 支持开机握手，且网络在 2 秒窗口内恢复；错过则继续等待下一次上电。
- 全部数据确认后若设备复位断网，烧录已完成，可重新连接读取版本。

注意：
- 整包一起拷贝，不要只拷贝 exe。
- Visual C++ 运行库一般不需要另装（MinGW 运行库已打进本目录）。
- 杀毒软件可能拦截串口/网络扫描，如打不开请加白名单。
